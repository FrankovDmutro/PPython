## Опис проєкту
Консольний потоковий застосунок для обробки великих наборів даних (системних логів) за принципом Lazy Evaluation з використанням генераторів, модуля `itertools` та `islice`. Застосунок мінімізує peak memory та запобігає переповненню RAM.

## Вимоги
* Python 3.11+
