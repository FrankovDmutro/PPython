# Облік наукових експериментів

## Опис

Консольний проєкт на Python 3 для обліку наукових експериментів.

Кожен експеримент містить такі поля:

- **Назва** (`name`)
- **Дослідник** (`researcher`)
- **Параметр** (`parameter`)
- **Результат** (`result`)
- **Дата** (`date`)

Проєкт реалізує такі операції:

- додавання експерименту;
- пошук експериментів за дослідником;
- обчислення середнього результату;
- пошук мінімального та максимального результатів;
- фільтрація експериментів за діапазоном результатів.

## Вимоги

- Python 3.10 або новіша версія;
- `pip`;
- Windows PowerShell або інший термінал.

## Встановлення

Клонуйте репозиторій і перейдіть до його кореневої директорії:

```powershell
git clone <repository-url>
cd PPython
```

Створіть і активуйте віртуальне середовище:

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
```

Встановіть проєкт у режимі editable:

```powershell
python -m pip install -e .
```

## Запуск

Запуск як Python-модуля:

```powershell
python -m lab_logging.main
```

Запуск через консольну команду:

```powershell
lab-logging
```

## Структура проєкту

```text
PPython/
├── pyproject.toml
├── README.md
└── src/
	└── lab_logging/
		├── __init__.py
		├── main.py
		├── models.py
		└── services.py
```

- `models.py` містить модель `Experiment`.
- `services.py` містить функції роботи з експериментами.
- `main.py` містить демонстраційний консольний сценарій запуску.
- `pyproject.toml` містить конфігурацію пакета та консольної команди.
